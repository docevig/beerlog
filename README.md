# beerlog

Дневник выпитого пива в виде Telegram Mini App. Отметка в два тапа, история,
статистика по стилям и календарь-теплокарта. Работает без собственного сервера:
статика лежит на GitHub Pages, данные — в Telegram CloudStorage.

## Разработка

```
npm install
npm run dev
```

Приложение открывается в обычном браузере и работает на localStorage —
Telegram для разработки не нужен. Отсутствие синхронизации в этом режиме
приложение показывает плашкой сверху.

```
npm run test    # модульные тесты
npm run build   # проверка типов и production-сборка
```

## Как устроено

- `src/storage/` — слой хранилища: интерфейс `KeyValueStore` и две реализации,
  облачная и локальная. Выбор происходит один раз при старте по версии Bot API.
- `src/lib/` — расчёты без побочных эффектов: границы суток, статистика,
  форматирование. Здесь же лежат тесты.
- `src/store/entries.ts` — загрузка и запись отметок помесячно.
- `src/views/` — три экрана, `src/components/` — их части.

Ограничения CloudStorage: 1024 ключа на пользователя, до 4096 символов
на значение. Месяц отметок пишется в ключ `log_YYYY_MM`, при переполнении
слой хранилища сам заводит следующий сегмент.

Сутки для статистики начинаются в 06:00: кружка в час ночи относится
к предыдущему вечеру.
